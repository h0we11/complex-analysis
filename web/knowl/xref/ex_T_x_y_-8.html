Exercise 9.
Find the temperature function \(T(x,y)\) in the first quadrant \(x>0,\,y>0\) that satisfies the following boundary conditions (shown in Figure 10.5.18).
\begin{align*} T(x,0) \amp = 100 \; \text{ for } \; x > 1;\\ T(0,y) \amp = -50 \; \text{ for } \; y > 1;\\ \frac{\partial T}{\partial n} \amp = T_y(x,0) =0 \; \text{ for } \; 0 \lt x \lt 1;\\ \frac{\partial T}{\partial n} \amp = T_x(0,y) = 0 \; \text{ for } \; 0 \lt y \lt 1\text{.} \end{align*}
🔗
Solution.
\(T(x,y)=25+\frac{150}{\pi}\mathrm{Re}(\mathrm{Arcsin}z^2)\text{.}\)
