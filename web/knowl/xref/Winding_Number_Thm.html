Theorem 8.7.9. winding numbers.

Suppose that \(f\) is meromorphic in the simply connected domain \(D\text{.}\) If \(C\) is a simple closed positively oriented contour in \(D\) such that for \(z\in C\text{,}\) \(f(z) \ne 0\) and \(f(z) \ne\infty\text{,}\) then
\begin{equation*} W\big(f(C) ,a\big) = \frac{1}{2\pi i}\int_{C}\frac{f\,'(z)}{f(z)-a}\,dz\text{,} \end{equation*}
known as the winding number of \(\boldsymbol{f(C)}\) about \(\boldsymbol a\), counts the number of times the curve \(f(C)\) winds around the point \(a\text{.}\) If \(a=0\text{,}\) the integral counts the number of times the curve \(f(C)\) winds around the origin.
