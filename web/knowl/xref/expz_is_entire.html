Theorem 5.1.2.

The function \(\exp(z)\) is an entire function satisfying the following conditions:
  1. \(\exp\,'(z)=\exp(z)=e^z\;\) (using Leibniz notation we write \(\frac{d}{dz}e^z=e^z\));
    🔗
    🔗
  2. \(\exp(z_1+z_2) =\exp(z_1) \exp(z_2)\;\,\) (that is, \(\; e^{z_1+z_2}=e^{z_1}e^{z_2}\));
    🔗
    🔗
  3. If \(\theta\) is a real number, then \(e^{i\theta}=\cos \theta +i\sin \theta\text{.}\)
