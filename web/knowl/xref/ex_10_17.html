Example 10.5.9.

Find the steady state temperature \(T(x,y)\) for the domain \(D\) consisting of the upper half-plane \(\mathrm{Im}(z) > 0\text{,}\) where \(T(x,y)\) has the boundary conditions
\begin{align*} T(x,0) \amp = 1 \quad \text{for} \quad x>1, \quad \text{and} \quad T(x,0)= -1 \quad \text{for} \quad x \lt -1;\\ \frac{\partial T}{\partial n} \amp = T_y(x,0) = 0 \quad \text{for} \quad -1 \lt x \lt 1\text{,} \end{align*}
where (again) \(n\) is a coordinate measured perpendicular to the segment.
🔗
Solution.
The mapping \(w=\) \(\mathrm{Arcsin}(z)\) conformally maps \(D\) onto the semi-infinite strip \(v>0,\,-\frac{\pi}{2}\lt u\lt \frac{\pi}{2}\text{,}\) where the new problem is to find the steady state temperature \(T^*(u,v)\) that has the boundary conditions
\begin{align*} T^*\left(\frac{\pi}{2},v\right) \amp = 1 \quad \text{for} \quad v>0, \quad \text{and} \quad T^*\left(-\frac{\pi}{2},v\right) = -1 \quad \text{for} \quad v>0;\\ \frac{\partial T^*}{\partial n} \amp = T_{v}^*(u,0) = 0 \quad \text{for} \quad -\frac{\pi}{2} \lt u \lt \frac{\pi}{2}\text{.} \end{align*}
🔗
Using the result of Example 10.1.1, we can easily obtain the solution:
\begin{equation*} T^*(u,v) =\frac{2}{\pi}u\text{.} \end{equation*}
🔗
Therefore the solution in \(D\) is
\begin{equation*} T(x,y) = \frac{2}{\pi}\mathrm{Re}\big(\mathrm{Arcsin}(z)\big)\text{.} \end{equation*}
🔗
If an explicit solution is required, we can use Formula (9.4.4) to obtain
\begin{equation*} T(x,y) = \frac{2}{\pi}\mathrm{Arcsin} \frac{\sqrt{(x+1)^2+y^2} - \sqrt{(x-1)^2+y^2}}{2}\text{,} \end{equation*}
where \(-\frac{\pi}{2}\lt \mathrm{Arcsin}(t)\lt \frac{\pi}{2}\text{;}\) see Figure 10.5.10.
