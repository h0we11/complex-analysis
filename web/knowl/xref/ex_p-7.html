Task 10.6.7.b.

Find the electrostatic potential \(\phi(x,y)\) in the domain \(D\) that satisfies the boundary values shown in Figure 10.6.14:
\begin{align*} \phi(0,y) \amp = 100 \; \text{ for all } \; y;\\ \phi(x,y) \amp = 200 \; \text{ when } \; |z-5|=4\text{.} \end{align*}
🔗
Solution.
\(\phi (x,y)=200-\frac{200}{\ln 2}\ln\big|\frac{2z-6}{z+3}\big|\text{.}\)
