Exercise 8.

Find the temperature function \(T(x,y)\) in the domain \(0\lt r\lt 1,\,0\lt \mathrm{Arg}(z)\lt \alpha\) that satisfies the following boundary conditions (shown in Figure 10.5.17). Use \(w=\mathrm{Log}(z)\text{.}\)
\begin{align*} T(x,0) \amp = 100 \; \text{ for } \; 0 \lt x \lt 1;\\ T(x,y) \amp = 50 \; \text{ for } \; x+iy=z=re^{i\alpha}, \; 0 \lt r \lt 1;\\ \frac{\partial T}{\partial n} \amp = 0 \; \text{ for } \; x+iy=z=e^{i\theta}, \; 0\lt \theta \lt \alpha\text{.} \end{align*}
